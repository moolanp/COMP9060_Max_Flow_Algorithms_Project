# COMP9060_Max_Flow_Algorithms_Project
BCIT COMP 9060 Applied Algorithm Analysis Project

## Algorithms

Ford Fulkerson, Edmond Karp, Dinic, Preflow-Push, Ahuja-Orlin

## Setup

    Install Python3 and pip. 
    Required libraries include networkx, and pytest.
    pip install -r requirements.txt
    
## Running tests and benchmarks

For validity tests on all algorithms run:

    python -m pytest tests/test_.py -v

Find our benchmark testing attached in a Python Notebook with associated instructions and analysis.
